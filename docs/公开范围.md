# 公开源码范围

公开内容为 TypeScript 调度器、React 前端、自动测试、锁文件、通用文档、宿主注册脚本和只读测试服务。示例均使用占位路径，不携带现有主机配置。

以下内容留在本地，不进入 Git 历史：

- `.helmdesk/`：连接令牌、数据库、任务/会话记录、提示词、交付副本、日志、模型用量和配置备份。
- `.env*`、凭据文件、个人宿主配置及 IDE 配置。
- 开发验证记录、项目原始规划、历史任务编号、内部派发/验收脚本和设计草图。
- `node_modules/`、`dist/` 及测试生成物。

文档和脚本采用明确的公开文件清单，其他本地文件继续忽略。不要使用 `git add -f` 将这些内容加入仓库。公开新文档或脚本时，同时更新忽略规则和发布检查的清单。

提交前运行：

```sh
git add .
node scripts/check-publication.mjs
git diff --cached --stat
git diff --cached --check
```

发布检查读取 Git 暂存区，限制文件种类并检查常见令牌、私钥、带认证信息的 URL 和个人主目录路径；报告只显示位置与类别，不打印疑似秘密。它不能识别所有秘密，新增内容仍需人工审阅。测试中的固定假凭据和哈希用于验证边界，不是真实账户数据。
