# Mac 功能范围

本轮范围为 Mac 本地完整版；iOS 和手机网关暂缓。

| 规划领域 | 本地实现 |
| --- | --- |
| 运行与安装 | .app、锁定 Node、生产依赖、用户 Applications 安装、旧包保留 |
| 服务 | 私有身份、单实例、受控端口、空闲重启、断线恢复、休眠唤醒接入 |
| 原生设置 | 执行器、项目根目录、模型与深度、无推理诊断 |
| 数据 | 旧目录复用、schema 检查、升级前快照、WAL 一致性备份、摘要校验 |
| 交付 | 验证版本门禁、宿主审核、依赖放行、补丁预检与原生保存 |
| 宿主接入 | 安装路径稳定的 MCP 导出，保留 28 项工具 |
| 界面 | 既有主题与效果、分页、长内容折叠、静态降级和键盘焦点 |
| 分发准备 | 未签名 DMG、ZIP、校验值、组件许可清单、固定提交的 CI |

数据不自动搬家或覆盖新增记录；执行设置变化时派发准备会重新核对。执行完成、验证、验收与写回原项目仍是独立步骤。

GitHub 提供明示未签名、未公证的 Mac 预发布下载。正式签名公证与 iOS 仍待办；真实整机休眠、最低系统、Intel 和异机安装需要独立设备证据。私有规划与完整验收材料不随源码或包发布。
